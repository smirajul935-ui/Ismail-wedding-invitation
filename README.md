# Modern Luxury Wedding Invitation — Glow Edition

Static Bengali/Hindi wedding invitation — HTML + CSS + vanilla JS.
No backend, no build tools, no API keys. GitHub Pages ready.

**Ismail Ali Shah & Taslima Khatun** · 01 November 2026
**Venue:** Shyam Sarthak Palace, Dehiramnagor, Daspur, Paschim Medinipur

---

## Features
- Bilingual (বাংলা / हिन्दी) toggle
- Welcome screen with gold line-art portraits + glowing crest
- Luxury invitation card, programme, venue, live countdown
- Code-generated 9-scene cinematic wedding film (grain, light leaks, dust, camera moves)
- Background music that starts on the first touch anywhere on the page
- Floating music dock + tap-to-play hint
- Reduced-motion support, keyboard accessible, no horizontal scroll
